# Plaza OpenAPI spec

This repository contains an [OpenAPI](https://spec.openapis.org/oas/v3.1.0.html) specification for the [Plaza API](https://docs.plaza.fyi).

It is generated with [Stainless](https://www.stainless.com/).

## Spec

> [!CAUTION]
> This spec is primarily intended for Plaza's internal use. Stability of the spec is not guaranteed.

[**View the spec**](openapi.yml)
